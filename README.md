# Komentář k zákonu č. 157/2009 Sb., o nakládání s těžebním odpadem a o změně některých zákonů

Otevřený komentář k zákonu o nakládání s těžebním odpadem — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; úložná místa a jejich kategorie, plán pro nakládání s těžebním odpadem, povolení provozu, rezerva finančních prostředků, prevence závažných nehod, veřejná správa a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2009-00157_2024-01-01`.
